# PCL2 OE 用户界面与交互差异报告

> 面向用户整理，重点说明“从官方 PCL2 迁移到 PCL2 OE 时，哪些地方看起来、点起来不一样”。
> 本文只说明用户能看到、点到的差异。

## 一、结论

当前 PCL2 CE 与官方 PCL2 的差异，主要不是颜色和图标，而是：

- 顶部导航的名称和入口不同
- 启动页的登录区结构不同
- 设置页的分类方式不同
- “关于、反馈、更新、日志”所在的位置不同
- CE 多出一批官方没有的入口
- 官方的一些入口在 CE 里没有对应页面

如果只换配色，用户仍然会觉得“不是官方 PCL”。要做到接近无缝迁移，需要把**页面入口、导航顺序、登录区、设置分类、常用按钮位置**一起对齐。

现有定制会继续保留：

- 隐藏右侧 PCL CE 版本提示
- 隐藏更新后的版本说明弹窗
- 中国大陆可正常使用 MC 下载、补全、整合包安装
- 默认从本仓库更新
- 不登录微软账户也能创建离线/第三方档案
- 启动时不再出现正版购买劝导和赞助劝导

---

## 二、对比基准

- **官方 PCL2**：当前实际发布界面
- **PCL2 CE**：当前 2.15.1 界面
- 官方公开源码与实际发布版本存在少量差异，本文以**实际界面**为准

官方当前主界面给人的第一印象：

- 蓝色顶栏，左侧只有 PCL 标志
- 顶部四个入口：启动、下载、设置、更多
- 启动页左侧是“正版 / 离线”切换 + 账号区 + 启动按钮
- 右侧大面积留白，内容区比较克制

CE 当前主界面给人的第一印象：

- 标题是“Plain Craft Launcher Community Edition”
- PCL 标志旁边有 CE 徽标
- 顶部入口是：启动、下载、设置、工具
- 启动页右侧有主页卡片、日志等社区内容
- 设置页分类更多，关于/反馈也在设置里

---

## 三、总体差异表

| 区域 | 官方 PCL2 | 当前 PCL2 CE | 迁移影响 |
|---|---|---|---|
| 窗口标题 | Plain Craft Launcher | Plain Craft Launcher Community Edition | 高 |
| 左上标志 | 只有 PCL 标志 | PCL 标志 + CE 徽标 | 高 |
| 顶部入口 | 启动、下载、设置、更多 | 启动、下载、设置、工具 | 高 |
| 启动页登录区 | 正版/离线切换在页面顶部 | 没有顶部切换，档案入口在别处 | 高 |
| 设置分类 | 启动、个性化、其他 | 游戏、工具、启动器、关于四组 | 高 |
| 关于/反馈 | 在“更多”里 | 在“设置”里 | 高 |
| 下载分类 | 原版游戏 + 社区资源；当前官方已不提供 MC 下载 | 分类更多，含安装器、世界、收藏等；保留完整 MC 下载 | 中 |
| 实例侧栏 | 概览、设置、修改、模组、禁用模组、导出 | 入口更多，含存档、截图、资源包、光影等 | 中 |
| 顶部图标 | 官方自绘图标 | 通用线条图标 | 中 |
| 主题色 | 官方蓝色 | 可换主题，默认观感不同 | 中 |
| 二级页面标题/按钮文案 | 官方措辞 | 部分为社区改写的措辞 | 中 |
| 动画/间距/圆角 | 官方节奏 | 接近，但局部不同 | 低 |

## 四、主窗口与顶栏

### 官方

- 默认窗口约 900×550，固定大小，只能最小化
- 顶栏高度约 48，蓝色渐变
- 左侧是 PCL 图形标志，没有额外徽标
- 中间四个入口：启动、下载、设置、更多
- 选中的入口是白色胶囊，未选中是白色文字/图标
- 右上角只有最小化、关闭

### CE

- 窗口可缩放，最小尺寸更小
- 标题带 Community Edition
- PCL 标志右侧多一个 CE 徽标
- 入口是：启动、下载、设置、工具
- 第 4 个入口的图标是扳手，官方是四宫格
- 右上角同样是最小化、关闭

### 用户迁移感

官方用户第一眼会注意到：

1. 标题和 CE 徽标
2. “工具”而不是“更多”
3. 第 4 个入口图标不同
4. 窗口可以拉伸，官方不能

### OE 建议

- 标题、左上标志、四个入口名称和顺序按官方
- 第 4 个入口改为“更多”，使用四宫格图标
- 默认窗口尺寸、顶栏高度、入口间距按官方
- 窗口是否允许缩放可以保留 CE 的缩放能力，但默认观感按官方
- CE 徽标不在主界面出现

---

## 五、启动页

### 官方

左侧固定宽度约 300，结构从上到下：

1. 正版 / 离线切换
2. 账号头像和账号选择
3. “添加新账号”下拉框 + 登录按钮
4. “购买正版”“前往官网”文字入口
5. 底部“启动游戏”大按钮
6. 按钮下方一行版本/状态提示

右侧是大面积浅色背景，内容很少。

### CE

左侧同样是账号/版本/启动按钮的结构，但：

- 没有顶部“正版 / 离线”切换
- 账号相关操作更依赖独立档案页面
- 右侧增加了主页卡片、公告、日志等模块
- 启动按钮和版本提示仍在，但文案和间距有社区改动

### 用户迁移感

这是差异最大的页面。官方用户已经习惯：

- 在启动页直接切正版/离线
- 在同一个下拉框里选账号并登录
- 看到“购买正版 / 前往官网”

CE 用户则习惯去档案页管理账号。迁移时，官方用户会找不到原来的切换和登录入口。

### OE 建议

启动页优先按官方重排：

- 顶部恢复“正版 / 离线”切换
- 账号区、下拉框、登录按钮按官方位置
- “购买正版 / 前往官网”保留为文字入口
- 底部启动按钮、版本提示按官方
- 右侧社区主页内容默认收起或弱化，避免第一眼不像官方
- CE 的档案管理能力保留，但入口不要抢启动页主视觉

---

## 六、登录与档案

### 官方

- 正版/离线是启动页顶部的一级切换
- 添加账号、登录、切换账号都在启动页完成
- 购买正版、官网入口紧挨着账号区

### CE

- 有独立的档案页面
- 档案类型包括微软、第三方、离线
- 新建档案时选择验证方式
- 启动页不再承担“正版/离线”一级切换

### 用户迁移感

官方用户会认为“登录入口变深了”；CE 用户则可能觉得官方把档案管理压缩在启动页。两边操作路径不同，需要 UI 层做兼容。

### OE 建议

- 启动页恢复官方的一级切换和登录区
- 点击后仍进入 CE 的档案/登录流程，不改变实际验证逻辑
- 档案页保留，作为“管理档案”的二级入口
- 新建档案的三种类型不变

---

## 七、下载页

### 官方

左侧只有：

- 原版游戏
- 社区资源：Mod、整合包、数据包、资源包、光影包

当前官方版本的“原版游戏”页不再提供 MC 下载，而是显示“为遵守相关法律法规，暂时不再提供”的说明。社区资源页仍然可用。

### CE

左侧分类明显更多：

- 原版游戏
- 社区资源：模组、整合包、数据包、资源包、光影、世界、收藏
- 安装器：OptiFine、Forge、NeoForge、Cleanroom、Fabric、LegacyFabric、LabyMod、LiteLoader 等

CE 的“原版游戏”仍然是完整可用的 MC 下载。

### 用户迁移感

官方用户会看到更多分类，但不一定找不到原来的入口；主要问题是侧栏更长、层级更多，第一眼不如官方简洁。

更重要的是：**官方已经不再提供 MC 下载，而 OE 的重点之一就是保留下载功能**。所以下载页不可能完全照官方复刻，只能是“官方布局 + CE 下载能力”。

### OE 建议

- 第一层保持官方的“原版游戏 / 社区资源”结构
- “原版游戏”保留 CE 的完整下载能力，不复制官方的“暂不提供”空状态
- 把 CE 多出的安装器、世界、收藏收进“更多安装方式”或二级入口
- 常用入口（原版游戏、Mod、整合包、资源包、光影）位置按官方
- 不删除 CE 的下载能力，只调整入口层级

---

## 八、实例/版本页

### 官方

左侧入口：

- 概览
- 设置
- 修改
- 模组
- 禁用模组
- 导出

### CE

左侧入口更多：

- 概览、设置、安装、导出
- 存档、截图
- 模组、禁用模组、资源包、光影、 Schematic、服务器

### 用户迁移感

官方用户会看到很多额外入口；CE 用户则习惯了这些入口。若完全按官方隐藏，会损失 CE 的便利性。

### OE 建议

- 第一屏保留官方 6 个入口的顺序
- CE 多出的入口收进“资源 / 更多”分组，不要与官方主入口混在一起
- “概览、设置、模组、导出”位置按官方
- CE 的存档、截图、资源包、光影等功能保留，但作为二级分组

---

## 九、设置页

### 官方

一级分类只有三个：

- 启动
- 个性化
- 其他

“关于、反馈、更新、日志”不在设置里。启动页显示“启动选项、内存分配”等分组，个性化页负责主题和外观。

### CE

设置页分成四组，入口更多：

- 游戏：启动、Java、游戏管理
- 工具：联机
- 启动器：界面、语言、杂项
- 关于：关于、更新、反馈、日志

### 用户迁移感

这是仅次于启动页的第二大差异。官方用户打开设置会发现分类名称、顺序、数量都变了；关于/反馈也不在原来的位置。

### OE 建议

- 一级分类按官方：启动、个性化、其他
- Java、游戏管理、语言、杂项收进“启动”或“其他”的二级区域
- 关于、更新、反馈、日志移出设置，放到“更多”
- 设置项本身不删除，只调整归属和顺序

---

## 十、更多 / 关于 / 帮助

### 官方

“更多”里有：

- 帮助
- 关于与鸣谢
- 百宝箱
- 反馈
- 新功能投票

### CE

“工具”里有：

- 多人游戏（大厅）
- 实用工具（测试）

“关于、更新、反馈、日志”在设置里。

### 用户迁移感

官方用户点“更多”想找关于/帮助，会发现在 CE 里变成了“工具”，而且关于在设置里。这是导航习惯的断裂。

### OE 建议

- 第 4 个顶部入口改为“更多”
- “更多”里按官方顺序放：帮助、关于与鸣谢、百宝箱、反馈、新功能投票
- CE 的多人游戏/大厅保留，放在“更多”的独立分组
- 关于页从设置迁移到“更多”
- 关于页内容按官方结构重排，常用信息（版本、更新、开源、反馈）位置一致
- 赞助链接直接显示完整 URL 文本，不做成超链接按钮或隐藏入口

## 十一、对话框、提示与文案

### 官方

- 提示偏少，措辞直接
- 启动失败、版本问题、登录问题的提示比较短
- 没有 CE 版本公告、社区提示

### CE

- 有 CE 版本说明、社区提示、更新提示等
- 部分提示文案更长、更社区化
- 已通过定制隐藏右侧 CE 提示和更新后弹窗

### 用户迁移感

官方用户会觉得 CE 的提示更多、更啰嗦；但核心错误提示还能看懂。

### OE 建议

- CE 专属公告默认不出现
- 通用提示的标题、按钮顺序、措辞按官方
- 长说明收进“详情”或帮助页，不占主流程
- 保留必要的错误信息，不为了像官方而删掉关键提示

---

## 十二、交互与快捷键

### 相同或接近

- 启动页回车启动
- 实例选择 F11
- 顶部返回按钮
- 拖拽文件导入
- 右键菜单的基本结构

### 不同

- 顶部入口数量/顺序不同，切换路径不同
- 官方启动页可直接切正版/离线，CE 需要去档案页
- 官方“更多”与 CE“工具”的内容不同
- 设置页层级不同，找同一个选项的点击次数不同
- 部分按钮的默认焦点、确认/取消顺序不同

### OE 建议

- 常用路径按官方：启动页登录 → 选版本 → 启动
- 设置路径按官方：设置 → 启动/联机/界面/系统
- 关于/反馈路径按官方：更多 → 关于/反馈
- 快捷键保持现有 CE 能力，不为了对齐而删除

---

## 十三、视觉风格

### 官方

- 主色：蓝色
- 顶栏：蓝色渐变
- 内容区：白 + 浅蓝
- 圆角、阴影、间距比较克制
- 图标为官方自绘风格

### CE

- 支持主题切换，默认观感与官方不同
- 顶部图标为通用线条图标
- 部分卡片圆角、间距、阴影更“社区化”
- 右侧主页内容更多，视觉更满

### OE 建议

- 默认主题改为官方蓝色系
- 顶栏、按钮、选中态、圆角、间距按官方
- 顶部四个图标换成官方风格
- 右侧主页默认弱化，保持官方留白感
- 主题切换、自定义主页等 CE 功能保留，但不作为默认第一眼

## 十四、迁移体验总结

### 高影响（必须先改）

1. 标题、CE 徽标、顶部四个入口
2. 启动页正版/离线切换和登录区
3. 设置页一级分类
4. 关于/反馈从设置移到更多
5. “工具”改“更多”及内容重排

### 中影响（第二阶段）

1. 下载页分类收拢
2. 实例页侧栏分组
3. 顶部和常用按钮图标
4. 默认主题色和间距
5. 常用提示文案

### 低影响（后续打磨）

1. 动画节奏
2. 圆角/阴影细节
3. 冷门页面文案
4. 关于页排版
5. 工具提示和帮助文本

## 十五、OE 分阶段计划（用户视角）

### 第一阶段：第一眼像官方

- 顶栏、标题、标志、四个入口
- 启动页登录区和启动按钮
- 设置页一级分类
- 更多页和关于页位置
- 默认蓝色主题

验收标准：

- 不看标题，第一眼能认出是官方 PCL 的布局
- 官方用户能在原来的位置找到登录、启动、设置、关于
- CE 的定制仍然保留

### 第二阶段：常用页面顺手

- 下载页分类收拢
- 实例页侧栏分组
- 常用按钮和图标
- 提示文案

验收标准：

- 下载、装模组、装整合包、改实例设置的路径与官方接近
- CE 独有功能仍然找得到

### 第三阶段：细节一致

- 右键菜单、对话框、快捷键
- 动画、间距、圆角
- 冷门页面和帮助页

验收标准：

- 连续使用一段时间后，不会因为小差异频繁迷路
- 官方用户不需要重新学习

---

## 十六、需要提前确认的取舍

要做到“尽可能像官方”，下面几件事必须做取舍：

1. CE 多出的下载分类、实例入口，是收进“更多/高级”，还是保留在首屏？
2. 官方不能缩放窗口，CE 可以缩放；OE 是否保留缩放？
3. CE 的自定义主页、主题、工具入口，是否保留？保留的话放在哪里？
4. 官方没有的 CE 功能，是隐藏、降级，还是放在“更多”里？
5. 关于页从设置移到更多后，设置页是否还保留“关于”快捷入口？
6. 官方已经不再提供 MC 下载，OE 必须保留 CE 的下载能力；下载页只能做到“官方布局 + CE 功能”，不能完全照官方复刻

建议原则：

- 官方用户高频路径优先
- CE 独有能力保留，但不抢第一屏
- 首屏尽量简洁，二级页面再展开
- 不为了“像”而删除实用功能

---

## 十七、总体判断

- 只做配色和图标：只能算“像一点”，迁移体验提升有限
- 做顶栏 + 启动页 + 设置分类：能解决大部分“找不到入口”的问题
- 再做下载/实例页：日常使用路径基本顺了
- 最后做菜单/对话框/动画：接近“无缝迁移”

按当前差异量，这不是一次小更新，而是持续几个阶段的 UI 对齐工作。建议先完成第一阶段，发布一个 OE 预览版，用真实 PCL2 用户的反馈决定后续优先级。
